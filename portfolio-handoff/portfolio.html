Case Study

Foundations of Supportive Counseling

A full branching counselling simulation, built stage by stage through the ADDIE model — from the first SME conversation to the finished Storyline build. This is a portfolio piece, not real client work, built to demonstrate skill.

The ADDIE Process

How I built it

01

Analyse

As part of the first phase, this is my systematic curriculum approach:

  • Analyse the raw materials provided by the SME
  • Conduct basic research on the topic
  • Meet the SMEs to determine requirements, scope and confirm a basic curriculum flow

Learning objectives are framed using Bloom's Taxonomy, so each one names a behaviour the learner should be able to do.

Recognise the importance of foundational verbal and non-verbal techniques in supportive conversations
Identify core verbal and non-verbal techniques used in supportive conversations
Apply active listening, open-ended questions, paraphrasing, and reflecting feelings in a simulated session

An overall workflow will then be designed and, with the rest of the gathered information, mapped into a Curriculum Design Document (CDD) which helps the SME have an overall view of the full flow of the course before a single slide is built.

02

Design

The CDD becomes a storyboard: every screen planned and every line of narration drafted, mocked up directly in Storyline so the structure, pacing, and content can be reviewed before any branching logic goes in.

03

Develop

The storyboard gets built for real: variables, triggers, and branching logic wired up in Storyline, alongside work with graphic designers and stock or custom assets to give the module its final visual look.

Launch the module
04–05

Implement & Evaluate

Finally, the module goes live: working with the SME to place it on their LMS, then testing it with real learners to check whether it actually changes how they perform — not just whether they finished it.
