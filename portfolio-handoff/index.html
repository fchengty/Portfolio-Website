The ADDIE Process

How I built Foundations of Supportive Counseling

01

Analyse

Every module starts with the raw material: source documents, SME interviews, and existing training records. For this project I met with subject-matter experts to define the requirements and scope the content, then mapped it into a Content Design Document (CDD) — the document that plans the full flow of the course before a single slide is built. Learning objectives are framed using Bloom's Taxonomy, so each one names a behaviour the learner should be able to do, not just a topic they were exposed to.

Download the CDD
02

Design

The CDD becomes a storyboard: every screen planned, every line of narration drafted, before it's built in Storyline. At this stage placeholder assets stand in for final imagery, so structure and content can be reviewed without waiting on production art.

Develop

The storyboard gets built for real: variables, triggers, and branching logic wired up in Storyline, alongside work with graphic designers and stock or custom assets to give the module its final visual look.

04–05

Implement & Evaluate

Finally, the module goes live: working with the SME to place it on their LMS, then testing it with real learners to check whether it actually changes how they perform — not just whether they finished it.
